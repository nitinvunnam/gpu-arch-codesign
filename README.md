# GPU Architecture and Kernel Performance Co-Optimization

Exploring how GPU microarchitecture and CUDA kernel
optimizations interact to influence performance.

## Technologies
- C++ / CUDA
- Accel-Sim
- NVIDIA Nsight Compute
- Python

## Goals
1. Implement and benchmark CUDA kernels.
2. Experiment with simulated GPU architectures.
3. Analyze hardware/software performance tradeoffs.
4. Compare simulator predictions with real GPU measurements.

- SGEMM (planned)
